# Better Tradable Items (RimWorld)

**Better Tradable Items** adjusts the tradeability value of multiple items to allow them to be bought and sold. This mod takes substantial inspiration from existing mods which do this separately for different items, and adds some items that I personally wanted to see tradable. See the credits section for more information on sources used to create this mod.
