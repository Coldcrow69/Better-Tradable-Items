**Better Tradable Items Mod README**

**Mod Description**

Better Tradable Items adjusts the tradeability value of multiple items to allow them to be bought and sold. This mod takes substantial inspiration from existing mods which do this separately for different items, and adds some items that I personally wanted to see tradable. See the credits section for more information on sources used to create this mod. 

"Better Tradable Items" makes the following items buyable and sellable:
- Stone blocks
- Ambrosia
- Meals
- Serums
- Baby Food (with biotech)

The intention of this mod is to continue adding items that the community would like to see and build one comprehensive mod for tradable items. If you would like to have an item added to this mod and see it become tradable, leave a comment on the Steam workshop page.

**Installation Instructions**

Steam Workshop:
   - Open the Steam client and navigate to the RimWorld Workshop.
   - Search for "Better Tradable Items" in the Workshop search bar.
   - Click on the mod in the search results to access its Workshop page.
   - Click on the "Subscribe" button to download and automatically install the mod.

**Compatibility**

"Better Tradable Items" is designed to be a lightweight and highly compatible mod, and compatibility is built-in for some of RimWorld's most popular mods. However, please be aware that any mods which directly interacts with base game item tradeability values may conflict with "Better Tradable Items" and result in unintended behavior or unbalanced gameplay. It is recommended to check the mod descriptions and community forums for potential conflicts or patches if you are using other mods that affect trade mechanics.

**Requirements**

Before using the "Better Tradable Items" mod, ensure you have the RimWorld base game installed. DLCs are not required to use Better Tradable Items.

**FAQ**

Q: Can this be added mid-save?
A: Yes.

Q: Can this be removed mid-save?
A: Yes.

Q: Do I need the DLCs to use this mod?
A: No.

Q: Is this mod compatible with another mod?
A: Probably. This is an XML only mod, so the worst behavior that you should get is unintended item tradability. It's not likely to cause any crashes, and as long as the other mod doesn't modify tradeability values, it's unlikely there will be any conflict.

Q: I have a bug, and I think it's caused by this mod. What do?
A: Create a bug report post on the workshop page of the mod.

Q: Rimworld updated, but this mod hasn't yet. What do?
A: Life happens sometimes, but I will do my best to update all of my mods, including this one, as quickly as I can.

Q: I want to use your mod or pieces of your mod in mine, is that okay?
A: Yes. Review the LICENSE.txt file in the mod directory, and please credit me for my work in the documentation of your new mod, and on the steam workshop page.
